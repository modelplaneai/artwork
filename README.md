# Modelplane Artwork

Official artwork and logos for the Modelplane project.

## Structure

```
modelplane/
├── horizontal/       # Horizontal lockup (logo + text side by side)
│   ├── color/        # Full color
│   ├── black/        # Black (for light backgrounds)
│   └── white/        # White (for dark backgrounds)
├── icon/             # Icon mark only
│   ├── color/
│   ├── black/
│   └── white/
└── stacked/          # Stacked lockup (icon above text)
    ├── color/
    ├── black/
    └── white/
```

## File naming convention

```
modelplane-{layout}-{color}.{format}

# Examples:
modelplane-horizontal-color.svg
modelplane-icon-white.png
modelplane-stacked-black.svg
```

## Formats

Each variant is provided in:
- **SVG** — vector, preferred for web and print
- **PNG** — raster, for contexts where SVG is not supported
